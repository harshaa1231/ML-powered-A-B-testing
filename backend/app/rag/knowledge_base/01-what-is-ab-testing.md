# What is A/B Testing?

Imagine you own a lemonade stand. You want to know if a new sign brings in more customers than the old one. So you try both: on Monday, Wednesday, and Friday you use the old sign ("Version A" / control). On Tuesday, Thursday, and Saturday you use the new one ("Version B" / treatment). Then you compare how many cups you sold on each day.

That's A/B testing: you split traffic or users into two (or more) groups, expose each group to a different version of something, and measure which version performs better on a metric you care about.

Companies like Google, Amazon, Netflix, and Airbnb run thousands of A/B tests every year. Every button color, headline, pricing change, and feature rollout is typically tested this way before being shipped to everyone.

Key vocabulary:
- **Control (A)**: the current/baseline experience.
- **Treatment (B)**: the new experience being tested.
- **Metric / outcome**: the thing you measure to decide a winner (conversion rate, revenue per user, click-through rate, retention, etc.).
- **Randomization**: users must be randomly assigned to control or treatment so the two groups are comparable in every way except the change being tested.
